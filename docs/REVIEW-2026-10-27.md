# OUI-TAK review, 2026-10-27

Verdict: code is sound. Do not rewrite or re-test parser, tracker, CoT, or TLS. Remaining work is physical.

## Blockers, in order
1. No real detection captured yet. Installed firmware predates upstream 5d29b14 (2026-04-23): known BLE decode bugs, BLE only. Reflash current Unified main (6e5e282) before the live test. Flashing keeps stored mode 5.
2. firmware-serial.txt shows the board in ROM download mode ("waiting for download"). Bridge ignores it and reports connected. Unplug/replug recovers.
   - Log a loud error on "waiting for download" in linux_serial_bridge.py.
   - Watchdog: alert after ~60 s with no bytes (status lines come every 20-30 s).
3. linux_serial_bridge.py reopens the TTY after read errors, contradicting the 0.8 plan and risking resets. Reopen only if the device node vanished. Otherwise stop and alert.
4. Ignore the Wi-Fi config erase. Wi-Fi driver settings only, mode 5 survives, Sky Spy does not use Wi-Fi.
